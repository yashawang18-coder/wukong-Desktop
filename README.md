# Wukong Desktop

Wukong Desktop is a desktop-pet project with versioned character identity and animation assets.

## Asset workflow

- `main` contains project documentation and approved runtime integration rules.
- New identity and action assets are reviewed through dedicated asset branches and draft pull requests.
- Generated assets may be public; Wukong's real photographs must never be committed.
- A `candidate` asset is review-only and must not be registered for runtime use.
- An `approved` identity board freezes the character's appearance, but does not approve any animation.

See [ASSET_STRUCTURE.md](ASSET_STRUCTURE.md) for the directory and status conventions.
