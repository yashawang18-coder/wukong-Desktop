## 步态验收

目标自然慢速四拍步行。每帧分别标注 LF/RF/LH/RH 的 contact、stance、
swing、toe-off；检查支撑足滑动、落地顺序和头身连续性。
目标顺序 LH -> LF -> RH -> RF，左右相隔半周期。
同侧前后肢先后落地不等于同时落地；静态一帧不能证明步态错误。
参考：[犬步态研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3996037/)。

不得用中途镜像、插值、滤镜或逐帧缩放掩盖问题。先锁定完整关键姿态，
再补中间态；未通过前只做独立候选，旧素材保留。
