# 悟空自主日常候选 v1：Windows 审阅说明

这个包只用于主人视觉验收，不会把候选动作加入正式自主行为池。

## 包内素材

| 分组 | 动作 | 帧数 | 运行状态 |
|---|---|---:|---|
| 姿态过渡 | 站立 → 坐下 | 10 | 开发者审阅专用 |
| 姿态过渡 | 坐下 → 趴卧 | 12 | 开发者审阅专用 |
| 姿态过渡 | 趴卧 → 坐起 | 4 | 开发者审阅专用 |
| 姿态过渡 | 坐姿 → 站立 | 5 | 开发者审阅专用 |
| 活泼释放 | 开心轻跳 | 12 | 开发者审阅专用 |
| 活泼释放 | 开心转圈 | 16 | 开发者审阅专用 |
| 相关互动 | 趴姿摸摸回应 | 多 phase | 开发者审阅专用 |

六组自主日常候选合计 59 帧。它们逐字节复用已批准的浅麦芽金素材；当前仅改变候选语义和素材索引，没有重新生成、调色或修改透明边缘。

## 启动和进入审阅页

1. 运行 `Wukong.Desktop.exe`。
2. 双击桌面上的悟空，打开控制面板。
3. 开启左侧“开发者模式”，密码为 `0714`。
4. 打开“素材”页 → “普通素材” → “自主日常候选”。该页只有开发者认证后才显示。

## 每个动作如何审阅

1. 点击“逐帧/循环审阅”。
2. 默认勾选“循环播放”，先看完整连续动作是否流畅。
3. 取消“循环播放”，使用“上一帧 / 下一帧”检查关节、尺度、毛色和透明边缘。
4. 点击“切换为深色背景 / 切换为明色背景”，在两种底色上检查蓝边、透明破洞和细毛缺损。
5. 点击“在桌面强制展示”，检查 WPF 透明窗口中的真实显示尺寸、落点和动作结束后的姿态回落。

## 通过标准

- 必须仍是同一只浅麦芽金悟空，不能出现赤红旧素材或身份漂移。
- 身体尺度稳定，姿态过渡不跳帧，轻跳和转圈不出现肢体融合。
- 明色和深色背景都没有蓝边、透明破洞、裁切或异常光晕。
- 动作结束后能回到对应的已批准站、坐或趴卧 microloop。
- “自主日常候选”不应在无人操作时自行出现。

## 审阅边界

当前清单仍保持：

- `autonomous_semantics_owner_approved=false`
- `runtime_approved=false`
- `runtime_use=false`
- `may_enter_autonomous_pool_by_default=false`

只有主人明确确认动作语义和 Windows 实机渲染都通过后，才能另开提交修改这些门禁。不要直接修改本审阅包。
