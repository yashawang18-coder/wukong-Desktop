# Wukong Control Panel UX

## Current reference

`wukong-control-panel-v2.html` is the archived interaction reference for the
current control-panel refresh. It covers all six primary sections and includes
the approved profile tabs, model and memory tabs, album-directory binding,
sub-album editing, user-facing asset cards, and developer diagnostics.

The WPF implementation should preserve existing commands, persistence, runtime
gates, and developer-only diagnostics while following this document's visual
hierarchy. Technical identifiers belong in the developer section rather than
ordinary owner-facing asset cards.

## Earlier reference

`wukong-ux.html` is retained as the previous design reference. It is not the
source of truth for new WPF layout work.
