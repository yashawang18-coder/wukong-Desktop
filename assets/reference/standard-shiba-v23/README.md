# 悟空标准柴犬参考素材 V2.3

整理日期：2026-08-13

## 定位

本包保存的是目前已经统一为“同一只狗”的标准柴犬参考素材，用于后续构造新的悟空身份模板时对照姿态、体量、毛发和色彩关系。

它不是最终的“悟空真实身份母版”。当前形象仍带有标准化柴犬特征，真实悟空的眼形、嘴套、耳形、脸部比例及个体毛色分区需要在新模板中重新建立。

## 当前已确认标准

- 同一只标准柴犬，跨站、坐、趴姿态的体量基本一致。
- 成年柴犬比例，体型紧凑、略圆润，不做夸张 Q 版。
- 低饱和麦芽茶金，背部和耳根略深，胸口与脸颊为奶油白。
- 毛发以平顺短毛为主，不使用卷曲、浮雕状纹理。
- “微笑”指自然轻微张嘴并露出短舌，不使用人类式嘴角上扬。

## 后续新模板需要重点重建

- 悟空真实照片中的小三角眼与克制神态。
- 更符合原犬的耳朵大小、间距、角度及轻微不对称。
- 更长、更自然的嘴套和鼻梁过渡。
- 真实脸颊、额头、胸腹及后躯比例。
- 原始照片中的个体毛色边界、卷尾形态与其他非标准化细节。

在新的真实身份母版确认前，本包适合作为姿态与风格参考，不建议直接扩展为最终运行素材。
