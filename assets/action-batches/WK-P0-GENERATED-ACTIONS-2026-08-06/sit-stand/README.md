# Sit/Stand Import

This package records three owner-approved sit/stand key poses and five runtime-candidate intermediate frames for sit-down and stand-up playback review.

The approved key poses may be used as derivation anchors. The runtime-candidate frames are not runtime-approved, not registered, and not enabled for application use.

Remaining gates: Windows desktop renderer playback, scale, pivot, alpha-edge, direction, memory, and interruption validation.
