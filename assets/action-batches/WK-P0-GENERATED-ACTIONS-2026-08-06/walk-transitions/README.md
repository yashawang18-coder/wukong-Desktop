# Walk Transition Import

This package records two owner-approved walk transition key poses, a walk-start runtime candidate, and the V4 geometry-stabilized walk-stop candidate frame.

The walk-stop import intentionally includes only the effective V4 `stop-i2` frame. Rejected `stop-i1` and `attempt2` evidence images are excluded.

No preview GIFs, contact images, video-derived files, or runtime registry bindings are included.
