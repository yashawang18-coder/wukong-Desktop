【完整动作过程】

Down v2稳定侧卧、头部抬起
→ 前胸轻微放松
→ 头、颈和前胸作为整体开始下沉
→ 嘴部逐渐闭合、舌头连续收回
→ 头部继续下降但不转向
→ 下巴逐渐接近两只前爪之间
→ 脸颊与下巴自然贴地
→ 保持黑眼睁开、安静贴地休息
→ 后侧胸腹出现两次非常轻微的呼吸
→ 原路抬头
→ 回到完全相同的 Down v2 起点

全程不转头，不左右看，不歪头。

动作重点是“头胸整体下沉、脸贴地”，不是转头、换脸或把头单独贴到身体上。
