# Wukong 正面趴姿微表情 v1

本批次从 `WK-FRONT-PRONE-EXPRESSIONS-CANDIDATE-v3.zip` 字节级复制 36 张透明生产 PNG，不包含 review 目录、APNG、WebP 或其他预览文件。

三组动作仅适用于 `prone.awake.front` 稳定正面趴姿：满足地笑一笑、好奇地看看、若有所思地看着。每组 12 帧、3030 ms、非循环，首尾均为当前正式正面趴姿锚点。

当前状态：素材视觉已确认；正式运行审批保持关闭，等待候选 EXE 中实际显示尺寸的表情强度与切入/回落连续性人工验收。开发者预览始终可用；只有候选发布目录存在 `Wukong.FrontProneExpressionsReview.enabled` 时，才临时开放低频自主调度。
