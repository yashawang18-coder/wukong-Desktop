# WK-AUTONOMOUS-DAILY-BEHAVIORS-v1

This is a review-only derivative batch for spontaneous daily behavior. It reuses only the approved light-malt-gold Wukong pixels from the v4 command production batch and the approved lifecycle batch.

The PNG bytes are copied without image processing. The new `wk.daily.*` IDs express proposed autonomous meaning; that semantic reuse still requires owner review and real Windows renderer QA. Therefore every runtime gate remains closed and the desktop catalog does not register this batch.

Run `python tools/build_autonomous_daily_v1.py` to reproduce the frame copies and manifest.
