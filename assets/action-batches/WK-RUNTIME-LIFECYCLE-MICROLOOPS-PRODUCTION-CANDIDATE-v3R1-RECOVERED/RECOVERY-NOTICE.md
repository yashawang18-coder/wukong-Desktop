# V3R1 recovery notice

The earlier transient V3 ZIP was not available in the workspace, remote branches, or persistent files. This package reconstructs the same 68-frame coverage from immutable repository V2 pixels. It is not claimed to be byte-identical to the earlier V3 build. The missing stand-idle V5 is represented by the repository V2 stand microloop expanded to twelve timing frames. No newly generated dog pixels are used.
