# Identity specification

## Frozen identity

- Species and type: adult Japanese Shiba Inu.
- Build: compact and slightly rounded, with restrained muscle definition.
- Head: fox-shaped face, short pointed muzzle, small triangular eyes and a
  black nose.
- Ears: upright, compact triangular ears with softly rounded tips.
- Coat: warm orange between the previously reviewed 02 and 03 color targets;
  cream muzzle, cheeks, chest, belly and inner legs.
- Tail: dense, high-set curled tail.
- Default expression: neutral and attentive.
- Expression anchor: natural tongue-out smile matching the approved revision
  05 board.

## Anchor coverage

The approved board freezes front, left-front, left profile, right-front and
rear-three-quarter neutral geometry, plus the tongue-out smile expression.

## Usage constraints

- Do not use real photographs as repository assets.
- Use the closest board direction as the geometry reference for new actions.
- Keep action changes local to pose, expression and motion; do not regenerate
  the character identity independently.
- Do not infer runtime approval for an action from this identity approval.
